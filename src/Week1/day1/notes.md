### What I learned

- The modulus operator (`%`) is essential for divisibility checks
- The order of conditions in `if / else if` statements affects output
- Functions take input, process logic, and return output
- Functions can be declared using `function` or assigned to variables using `const`
- Built-in methods like `reverse()` solve tasks quickly but can hide underlying logic
- Writing logic manually improves understanding of loops and indexing
- Loops operate using indexes, and indexes must be used to access actual values
- Objects can be used to count occurrences of values
- Arrays and objects often work together to solve data problems

---

### Key mistakes I made

- Compared indexes instead of actual values
- Used incorrect loop direction (`i++` instead of `i--`)
- Misused `.includes()` by checking the wrong data structure
- Declared variables but referenced different names later
- Returned values inside loops before processing completed
- Relied on built-in methods before understanding manual logic
